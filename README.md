<p align="center">
<b><span style="color:#8000ff;">Hotbar Auto Fill</span></b> refills your selected hotbar slot from matching items in your inventory.
<br>
It is client-side only and works on vanilla and Bukkit/Paper servers.
</p>

---

## <span style="color:#8000ff;">Features</span>
- refills used-up items and broken tools
- checks the main inventory first
- optional hotbar fallback
- optional tool protection before break
- ignores manual moves, drops, and swaps

---

## <span style="color:#8000ff;">Config</span>
`config/hotbarautofill.properties`

- `refillFromOtherHotbarSlots=true`
- `preventToolBreakingWithoutReplacement=false`

---

## <span style="color:#8000ff;">Compatibility</span>
- Fabric: Minecraft `26.1` through `26.1.2`
- NeoForge: Minecraft `26.1` through `26.1.2`
- Fabric builds need Fabric API.

---

## <span style="color:#8000ff;">Installation</span>
Install the Fabric or NeoForge jar on the client. Servers do not need this mod or any plugin.
